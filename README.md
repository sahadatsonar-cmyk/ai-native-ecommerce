## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript (strict)
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui (New York style)
- **Database**: PostgreSQL + Drizzle ORM
- **Auth**: Auth.js
- **Validation**: Zod
